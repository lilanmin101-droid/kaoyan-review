## 流程（两种宽度相同）
1. 在 UI 注册新账号 → 进 #/quiz（点“刷题”tab），等 6 s → **题包没写入 localStorage**，F5 一次后才缓存（26 道 = 25 plan + 1 wrong_redo；SW 已接管页面）。
2. 断网 → 出现离线条和离线题包页（p04/p18）。
3. 第1题选 B（对）、第2题选 A（故意错，正确是 C）、第3题 B（对）、第4题 C（对），每题之间停 3–7.5 s。
4. 离线时按 F5 → 页面照常打开（SW 缓存），进度和判定都还在（p07–p08 / p21–p22）。
5. 点“下一题”到错题重做的 2025-47 翻译题（**要点 24 次**）→ 写思路 → 看参考答案 → 自评“没思路”（p09–p10 / p23–p24）。
6. 恢复联网 → 每 100 ms 检查一次离线条、队列和 toast → 用 API 核对 → 重放 2 条 → 截错题本和今日页。

## 考生视角的别扭点
1. **[两种宽度] 刚注册/登录完没有题包**：要刷新一次才缓存。考生登录后直接去地铁上断网，会发现没有离线题包。（p03/p17）
2. **[两种宽度] 翻译题原文里露出 HTML 标签**：离线题包的翻译原文直接显示 `<u data-q="48">…</u>`。passage english1-2025-P-translation 带 `<u>` 标记，离线页按纯文本渲染了。（p10，390 同样）
3. **[两种宽度] 错题重做排在最后，要点 24 次“下一题”**：题包页说“加 10 道错题重做”，但实际只有 1 道，而且没有入口能直接跳过去。（p09/p23）
4. **[两种宽度] 离线说明写“加 10 道错题重做”**：实际只有 1 道，数字对不上。（p04/p18）
5. **[两种宽度] 页头和内容对不上**：顶栏还是“2024 真题”，选中的是“数学一”，但下面做的是 2025 英语一完形。（p04/p18）
6. **[两种宽度] 页头缺空格**：“2026-11-02做了 0 / 26”，日期和“做了”粘在一起。（p04/p18）
7. **[两种宽度] 恢复联网后跳走**：直接跳回在线的 2024 数学一页面，而且停在页面中间（390 停在答题卡）。刚才做的英语和那条 toast 跟眼前的页面没关系，考生会愣一下。（p12/p26）
8. **[两种宽度] 完形小题题干不指明是哪个空**：第2题题干是整句“…is (1)___ … to (2)___ sink”，两个空都显示，看不出这题问的是 (2)。（p06/p20）
9. **[两种宽度] 选错的选项不够显眼**：只有字母 A 变红，整行没有底色，正确的 C 只有浅灰底。在线错题本里的“你当时选的”就清楚多了。（p06/p20 对比 p13）
10. **[两种宽度] 离线 F5 后的位置**：停在第5题中间，离线条和“4 道等联网补传”都在视野外，要往上滚才知道自己是离线状态、做到第几题。（p07/p21）
11. **[390] 翻译题自评按钮的措辞**：“全对 / 思路对，算错了 / 没思路”，“算错了”是数学的说法，放在翻译题上很怪。第三个按钮“没思路”换行后被底部导航挡住，要再滚一下才看得到。（p23）
12. **[两种宽度] 今日页和题包说法矛盾**：今日页写“今天还没排任务”，但题包说的是“今天任务里的阅读、完形”。补传后今日页也看不出今天做了 5 道。（p14/p28）
13. **[API，小问题]** GET /answers 流水不返回 study_date；`?question_ids=` 的 latest 模式里 source 和 study_date 都是 null。“计入今天”只能靠 /me/stats 核对。
